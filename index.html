HTTPS 지원

별도의 서버 비용 없이 GitHub에 이 HTML 파일 하나만 올리면 전용 모바일 앱 주소(`https://아이디.github.io/저장소명`)가 생성되며, 카메라 QR 스캔이 완벽히 작동합니다.

  1. GitHub 로그인 후 우측 상단 + → New repository를 클릭합니다.
  2. 저장소 이름(예: gas-manager)을 입력하고 Public으로 생성합니다.
  3. uploading an existing file을 눌러 이 코드를 저장한 index.html 파일을 업로드합니다.
  4. 저장소 상단 Settings → 좌측 메뉴 Pages로 이동합니다.
  5. Branch를 main으로 선택 후 Save를 누르면 1분 뒤 모바일 접속 링크가 발급됩니다!
